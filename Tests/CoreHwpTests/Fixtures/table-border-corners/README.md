# table-border-corners

`document.hwp`는 **한글 문서**(호환 문서 대상 프로그램 `HWP201X`)에 셀 간격이 없는 표의 셀 테두리
모서리 표본 — 단선·여러 줄·물결 변이 다른 모양·굵기·선 없음 이웃과 만나는 1×1 표, 같은 모양 격자의
교차점, 머리 행 2중선, 실선 사슬, 칸마다 색이 다른 다칸 표 — 을 실은 HWPX를 한컴오피스 한글 12.30.0
(build 6446)에서 열어 2026-10-02에 `한글 문서 (*.hwp)`로 저장한 binary HWP fixture다. 한글이 표 셀
테두리의 **시작·끝 자리와 그리는 차례**를 정하는 규칙(#246)의 실물 근거다 — 단선은 여러 줄·물결
이웃 쪽 끝을 가로·세로 모두 물리고, 선 없음 이웃도 저장된 굵기만큼 나가며, 여러 줄·물결은 모양·
굵기가 같은 이웃과만 부속선마다 맞물리고(교차점 ╬) 다르면 표 격자의 이어짐·지나감으로 끝 자리가
갈리고, 같은 물결 이웃이면 변 전체를 옮긴다. 셀 간격이 없는 표의 실선은 격자선을 따라 한 선으로
잇고, 그리는 차례는 여러 줄·물결 → 단선 세로 → 단선 가로 → 바깥 테두리 덧긋기다. 같은 편집
세션에서 저장한 HWPX 쌍(`HwpxFixtures/table-border-corners`)과 PDF 내보내기(2쪽)가 같은 문서다.

## 포함 기능

- 한 구역, 최상위 25문단(2쪽) — 첫 문단은 구역 정의를 품은 제목(`#246 table-border-corners`)이다.
  이어 표본마다 글자처럼 취급 표 하나 + 꼬리표(` #0`…` #11`, 7pt)를 실은 문단과 구분 문단(`-`)이
  번갈아 온다. 문단 모양은 왼쪽 정렬·줄 간격 비율 160%다.
- 표는 모두 셀 간격 0, 표 테두리 없음, 셀 안 여백 0이고 셀마다 7pt 빈 문단 하나를 싣는다. 색은 초록
  `#00FF00`·파랑 `#0000FF`·자홍 `#FF00FF`·청록 `#00FFFF` = 테두리 표본, 빨강 `#FF0000` = 기준 실선
  0.1mm다. 모든 표는 끝에 테두리 없는 20pt 칸과 빨강 기준 칸(30pt, 표의 모든 행에 걸친다)을 더해
  한글 PDF에서 표 원점을 정확히 잡게 했다. 테두리를 주지 않은 변은 선 없음 0.1mm다.
  - `#0` 1×1 (150×30pt) — 위 변 초록 실선 1mm + 왼·오른 변 파랑 2중선(`DOUBLE_SLIM`) 2mm
  - `#1` 1×1 (30×60) — 왼 변 초록 실선 1mm + 위·아래 변 파랑 2중선 2mm
  - `#2` 1×1 (150×30) — 위 변 초록 실선 1mm + 왼·오른 변 선 없음(`NONE`) 굵기 2mm
  - `#3` 1×1 (150×30) — 위 변 초록 2중선 1mm + 왼·오른 변 파랑 실선 2mm
  - `#4` 1×1 (30×60) — 왼 변 초록 물결(`WAVE`) 1mm + 위·아래 변 파랑 실선 2mm
  - `#5` 2×2 (칸 80×40) — 칸마다 네 변 2중선 1mm, 칸 색 초록·파랑 / 자홍·청록
  - `#6` 3×2 (칸 80×30) — 머리 행 아래(첫 행 아래 변·둘째 행 위 변) 초록 2중선 0.5mm, 나머지 파랑
    실선 0.12mm
  - `#7` 2×2 (칸 80×40) — 칸마다 네 변 실선 1mm, 칸 색 초록·파랑 / 자홍·청록
  - `#8` 1×3 (칸 60×30) — 위 변 초록 실선 1mm 세 칸 + 안쪽 세로 격자선 파랑 2중선 2mm(양쪽 칸)
  - `#9` 1×3 (칸 60×30) — `#8`과 같되 가운데 칸 위 변만 자홍 실선
  - `#10` 2×2 (칸 80×40) — 칸마다 네 변 물결 1mm, 칸 색 초록·파랑 / 자홍·청록
  - `#11` 1×1 (150×40) — 위·아래 변 초록, 왼·오른 변 파랑의 가는+굵은 2중선(`SLIM_THICK`) 1mm
- 표 12개(셀 수 3·3·3·3·3·6·8·6·5·5·6·3), `HWPTAG_COMPATIBLE_DOCUMENT` 대상 프로그램 0(`HWP201X`)
- PreviewText/PreviewImage stream, BinData storage 없음

## 재생성 절차

1. `HwpxFixtures/CharShape/document.hwpx`를 풀어 `header.xml`에 `hh:charPr id="0"`을 복제해 모든
   슬롯 함초롬바탕(글꼴 id 1) 7pt 글자 모양을, `hh:paraPr id="0"`을 복제해 왼쪽 정렬 줄 간격 비율
   160% 문단 모양을 만들고, 표본의 변 조합마다 `hh:borderFill`(`hh:leftBorder`·`hh:rightBorder`·
   `hh:topBorder`·`hh:bottomBorder`의 `type`·`width`·`color`; 주지 않은 변은 `type="NONE"`·
   `width="0.1 mm"`)을 더한다. `section0.xml`은 제목 문단(`hp:secPr`)에 이어 위 표본을
   `hp:linesegarray` **없이** 적는다 (한글이 새로 조판하게) — 표는 `treatAsChar="1"`·`cellSpacing="0"`의
   `hp:tbl`이고, 칸마다 `hp:cellAddr`·`hp:cellSpan`(빈 칸·기준 칸은 행 병합)·`hp:cellSz`와 여백 0의
   `hp:cellMargin`, 표본별 `borderFillIDRef`를 준다. 꼬리표는 표와 같은 run의 `<hp:t> #N</hp:t>`다.
   `mimetype`을 `ZIP_STORED` 첫 항목으로 다시 압축한다 (로컬 `probes/246` `gen246.py fixture`).
2. 그 HWPX를 `open -b com.hancom.office.hwp12.mac.general`로 연다.
3. `파일 > PDF로 저장하기...`로 같은 세션의 PDF를 내보낸다 (2쪽, A4).
4. `파일 > 다른 이름으로 저장하기...` → 파일 형식 **한글 문서 (*.hwp)** → 파일명만 입력 →
   저장 (System Events: 저장 패널 `splitter group 1`의 `pop up button 2`·
   `text field "별도 저장:"`·`button "저장"`; 같은 이름이 있으면 시트의 `button "대치"`).
5. 같은 세션에서 다시 `다른 이름으로 저장하기...` → **한글 표준 문서 (*.hwpx)** → 저장해
   `HwpxFixtures/table-border-corners/document.hwpx`를 갱신한다.
6. 저장된 `.hwp`를 이 디렉터리의 `document.hwp`로 복사하고 `manifest.json`의 기대값을
   갱신한 뒤
   `swift test --filter "FixtureManifest|HwpxFixtureManifest|HwpxHwpEquivalence|FixtureRender|FixtureTableBorderCorner"`로
   검증한다. 한글 PDF가 바뀌면 `FixtureTableBorderCornerTests.samples`를 `probes/246` `fxdata246.py`로
   다시 뽑는다.

생성 확인 환경:

- 앱: 한컴오피스 한글 (`com.hancom.office.hwp12.mac.general`)
- 버전: `12.30.0` build `6446`
- 생성일: 2026-10-02

## 한글.app 실측

같은 세션의 PDF 내보내기에서 표본마다 테두리 요소의 좌표를 빨강 기준 칸으로 잡은 표 로컬 좌표(첫 칸
왼 위 모서리 = 0, pt, 0.12pt 장치 격자)로 읽은 값이다. 표 원점이 장치 격자에 맞춰지고 선 끝은 장치
한 칸을 더 그려 끝 자리가 1~1.5u 흔들린다.

- 단선은 여러 줄·물결 이웃 쪽 끝을 가로·세로 모두 이웃 획(2mm 47u)의 절반만큼 물린다 — `#0` 위 변
  2.72 ~ 147.20, `#1` 왼 변 2.76 ~ 57.24. 그 모서리는 2중선도 초록 획의 절반만큼 물러나(`#0` 파랑
  1.44 ~ 29.88) 비어 있다.
- 선 없음 이웃도 저장된 굵기의 절반만큼 나간다 — `#2` 위 변 −2.80 ~ 152.84. 주지 않은 변(선 없음
  0.1mm)도 0.12만큼이다 (`#8` 위 변 −0.16 ~ 180.08).
- 다른 모양 이웃과 만나는 2중선은 두 부속선이 같은 자리다 — `#3` −2.80 ~ 152.72(겹상자 없음).
  물결 세로 변은 이웃 반폭만큼 물러난 2.88에서 첫 대각선을 시작한다 (`#4`).
- 같은 2중선 격자는 칸마다 닫힌 모서리를 만든다 — `#5` 칸 (0,0) 위 변 바깥 부속선 −1.44 ~ 81.48
  (교차점 너머로 이어짐)·안쪽 0.72 ~ 79.32, 아래 변 두 부속선 0.72 ~ 79.32, 왼 변 바깥 −1.44 ~ 41.40·
  안쪽 0.72 ~ 39.24.
- 머리 행 2중선은 세로 실선이 위아래로 지나가는 바깥 모서리에서 물러나고(`#6` 0.24) 같은 2중선이
  이어지는 가운데 모서리에서 멈춘다(80.04). 세로 실선은 2중선을 가로질러 한 선이다 (0 ~ 90).
- 실선은 격자선을 따라 한 선이다 — `#8` 위 변 세 칸이 한 선 −0.16 ~ 180.08(안쪽 2중선과 무관),
  `#9`는 자홍 칸이 사슬을 끊어 초록 −0.16 ~ 57.20 · 122.72 ~ 180.08, 자홍 62.72 ~ 117.20.
- 같은 물결 이웃은 변 전체를 옮긴다 — `#10` 위·왼 변 −1.44, 아래·오른 변과 아래 행 위 변 0.72에서
  첫 대각선.
- 가는+굵은 2중선 상자는 부속선마다 이웃 부속선과 맞물린다 — `#11` 위 변 가는 선 −1.48 ~ 151.40·
  굵은 선 −0.04 ~ 149.24.
- 그리는 차례(PDF 그리기 순서) — 여러 줄·물결 변을 칸 차례로 먼저, 이어 단선 세로 격자선 → 가로
  격자선, 마지막으로 바깥 테두리를 다시 긋는다: `#7`은 자홍·청록 칸의 위 변이 초록·파랑 칸의 아래
  변 위에, 바깥 왼 변이 가운데 가로선 위에 온다.
