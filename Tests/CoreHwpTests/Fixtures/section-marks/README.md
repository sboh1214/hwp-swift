# section-marks

`document.hwp`는 한컴오피스 한글 12.30.0 (build 6446)에서 빈 문서로 시작해 구역 부속
표식 네 종류(새 번호 지정·쪽 감추기·책갈피·찾아보기 표식)를 넣고 2026-09-08에 저장한
binary HWP fixture다. 같은 편집 세션에서 `한글 표준 문서 (*.hwpx)`로도 저장해
`HwpxFixtures/section-marks/document.hwpx` 쌍을 만들었다 — HWPX 승격(#169)의 실측
오라클이다.

## 포함 기능

1쪽 3장, 구역 1개, 문단 5개. 컨트롤 11개(구역·단·쪽 번호 위치 각 1, 새 번호 3,
쪽 감추기 2, 찾아보기 표식 2, 책갈피 1).

| 위치 | 컨트롤 | 값 | 제어 문자 코드 |
|---|---|---|---|
| 1쪽 문단 1 | 쪽 번호 위치 `pgnp` | 가운데 위, 줄표 `-` | 21 |
| 1쪽 문단 2 | 찾아보기 표식 `idxm` | 키워드 `본문` | 22 |
| 1쪽 문단 2 | 쪽 감추기 `pghd` | `0x29` = 머리말·쪽 테두리·쪽 번호 | 21 |
| 2쪽 문단 3 | 새 번호 `nwno` | 쪽 번호 9 (속성 0) | 21 |
| 3쪽 문단 4 | 쪽 감추기 `pghd` | `0x16` = 꼬리말·바탕쪽·쪽 배경 | 21 |
| 3쪽 문단 4 | 새 번호 `nwno` | 그림 번호 5 (속성 3) | 21 |
| 3쪽 문단 5 | 찾아보기 표식 `idxm` | 키워드 `색인둘본문` | 22 |
| 3쪽 문단 5 | 새 번호 `nwno` | 각주 번호 7 (속성 1) | 21 |
| 3쪽 문단 5 | 책갈피 `bokm` | 이름 `표식 A1` (CTRL_DATA) | 22 |

**쪽 감추기 두 표본이 표 145의 여섯 비트를 전부 확정한다** — `0x29`(bits 0·3·5)와
`0x16`(bits 1·2·4)이 서로의 여집합이라 비트별 대응이 한 가지로 정해진다.
HWPX 쌍의 `<hp:pageHiding hideHeader hideFooter hideMasterPage hideBorder hideFill
hidePageNum>` 여섯 불리언과 자리 순서가 그대로 맞고, 표 132를 옮긴
`HwpSectionDefProperty`의 bits 0-5와도 같다.

**새 번호의 제어 문자 코드는 21이다** (18은 자동 번호 `atno` 전용). 세 표본이
번호 종류 `PAGE`(0)·`PICTURE`(3)·`FOOTNOTE`(1)를 함께 잠근다.

**찾아보기 표식의 문자열 뒤 6바이트**는 두 번째 키워드 길이 WORD(0) + UINT32(`-1`)다.
레거시 문서(`legacy-common-control-property`)는 같은 자리에 0을 적는다 — 저작기
버전 차이이고 `indexmarkInfo.rawTrailing`에만 남는다.

**책갈피 이름은 컨트롤 payload가 아니라 `CTRL_DATA` 자식**의 ParameterSet
`0x021B`(item id `0x4000_0000`, value type 1) 문자열이다 — 컨트롤 헤더는 4CC 4바이트가
전부다.

## 재생성 절차

1. 한컴오피스 한글에서 새 빈 문서를 만들고 `구역 부속 표식 견본` Return `첫째 쪽 본문`
   입력.
2. `입력 > 책갈피...` → 이름 `표식 A1` → 넣기.
3. `Ctrl+K`, `I`(찾아보기 표식 넣기) — 대화상자 없이 문단의 앞 텍스트가 키워드가 된다.
4. `쪽 > 쪽 번호 매기기...` → 가운데 위 → 넣기.
5. `쪽 > 감추기...` → 쪽 번호 · 쪽 테두리 · 머리말 체크 → 설정.
6. `쪽 > 쪽 나누기`, `둘째 쪽 본문` 입력, `쪽 > 새 번호로 시작...` → 쪽 번호 · 시작 9 → 넣기.
7. `쪽 > 쪽 나누기`, `셋째 쪽 본문` 입력, `쪽 > 감추기...` → 쪽 배경 · 꼬리말 · 바탕쪽 →
   설정, `쪽 > 새 번호로 시작...` → 그림 번호 · 시작 5 → 넣기.
8. Return `색인둘` 입력 후 `Ctrl+K`, `I`, `쪽 > 새 번호로 시작...` → 각주 번호 · 시작 7 → 넣기.
9. `파일 > 다른 이름으로 저장하기...`로 `한글 문서 (*.hwp)` 저장, **같은 세션에서** 다시
   `한글 표준 문서 (*.hwpx)`로도 저장해 `HwpxFixtures/section-marks/document.hwpx`를 만든다.
10. 저장본을 이 디렉터리의 `document.hwp`로 복사하고 `manifest.json`을 갱신한 뒤
    `swift test --filter "FixtureManifestTests|HwpxHwpEquivalenceTests|HwpxSectionMark"`를 실행한다.

생성 확인 환경:

- 앱: 한컴오피스 한글 (`com.hancom.office.hwp12.mac.general`)
- 버전: `12.30.0` build `6446`
- 생성일: 2026-09-08
