# ms-word-paragraph-end-box

`document.hwp`는 **MS 워드 호환 문서**(호환 문서 대상 프로그램 2, `CT_MSWORD`)에서 **문단 끝
글자**(CR, 코드 13)나 **한 줄 끝 글자**(LF, 코드 10)의 글꼴 줄 상자가 본문 글자보다 큰 줄을 여러
조건으로 실은 합성 HWPX를 한컴오피스 한글 12.30.0 (build 6446)에서 열어 2026-09-25에
`한글 문서 (*.hwp)`로 저장한 binary HWP fixture다. 한글이 끝 글자의 상자를 본문 상자 위에
**쌓아** 줄 상자를 정하는 규칙(#223)의 실물 근거이며, 한글이 저장한 줄 캐시
(`PARA_LINE_SEG`의 `lineHeight`·`textHeight`·`baselineDistance`·`lineSpacing`)와 같은 편집
세션에서 저장한 HWPX 쌍(`HwpxFixtures/ms-word-paragraph-end-box`)·PDF 내보내기 좌표가 렌더 핀의
오라클이다 (`HwpKitTests/FixtureMsWordParagraphEndBoxTests.swift`).

글꼴은 macOS 시스템 글꼴만 쓴다 — 한글 슬롯 **Apple SD 산돌고딕 Neo**, 라틴 슬롯 **Menlo**(기본)·
**Helvetica**·**Times New Roman**·**Apple SD 산돌고딕 Neo**. 한컴 글꼴 없이도 한글 PDF의 좌표를
재현할 수 있게 하려는 것이다. 문단 끝 글자는 마지막 글자 모양의 **라틴 슬롯** 글꼴로 줄에 선다
(#194).

## 포함 기능

- 한 구역, 최상위 25문단(표 셀 문단까지 31문단), **3쪽** — 첫 문단은 구역 정의 +
  `#223 ms word paragraph end box`(Apple SD 산돌고딕 Neo·Menlo 10pt, 줄 간격 100%)이다. 나머지는
  달리 적지 않으면 한글 Apple SD 산돌고딕 Neo·라틴 Menlo 10pt 본문에 줄 간격 160%이고, 문단 끝
  글자의 글자 모양은 문단 마지막의 빈 run으로 준다.
  - `A1 가나다 cr16`: 10pt 본문 + 16pt 문단 끝 글자(Menlo)
  - `A2 가나다 cr10`: 대조군 — 10pt 문단 끝 글자
  - `A3 menlo cr asd`: 라틴 글자(Menlo)만 + 라틴 슬롯이 Apple SD 산돌고딕 Neo인 10pt 문단 끝 글자
  - `에이사가나다라`: 한글 글자(Apple SD 산돌고딕 Neo)만 + Menlo 10pt 문단 끝 글자 — 끝 글자 상자가
    본문보다 작다
  - `A5 가나다 cr30`: 20pt 본문 + 30pt 문단 끝 글자(라틴 Apple SD 산돌고딕 Neo)
  - `A6 helv cr16`: Helvetica 10pt 본문 + Helvetica 16pt 문단 끝 글자 (CJK가 아닌 글꼴 갈래)
  - `A7 times cr asd16`: Times New Roman 10pt 본문 + 16pt 문단 끝 글자(라틴 Apple SD 산돌고딕 Neo)
  - `A8 …`: 네 줄로 넘어가는 10pt 문단 + 16pt 문단 끝 글자 — 마지막 줄만 커진다
  - `B1 100 cr16`·`B2 between5 cr16`·`B3 atleast26 cr16`: 10pt + 16pt 문단 끝 글자, 줄 간격 비율
    100%·여백만 5pt·최소 26pt
  - `L1 가나 ⏎tail`: 16pt run의 한 줄 끝 + 둘째 줄 `tail`(16pt) + 10pt 문단 끝 글자
  - `L3 가나⏎`: 10pt run의 한 줄 끝 + 빈 마지막 줄 + 16pt 문단 끝 글자
  - `L4 big⏎`: 16pt run의 한 줄 끝 + 빈 마지막 줄 + 10pt 문단 끝 글자 (1쪽 끝에 들어가지 않아
    2쪽 머리에서 시작한다)
  - `L5 after`: 10pt 대조 문단
  - `O1 가`(쪽 나누기로 3쪽): 10pt 본문 + 높이 30pt 글자처럼 취급 1칸 표(폭 30pt) + 16pt 문단 끝
    글자
  - `O2 가`: 같은 꼴의 26pt 표
  - `오삼가나`: 20pt 본문 + 25pt 표 + 20pt 문단 끝 글자 — 표가 본문 베이스라인과 본문 상자 높이
    사이에 든다
  - (글자 없음): 30pt 표만 + 10pt 문단 끝 글자
  - `U1 가나다 under`: 10pt 글자 아래 밑줄(빨강) + 16pt 문단 끝 글자
  - `U2 menlo under`: 라틴 글자(Menlo) 10pt 밑줄 + 라틴 Apple SD 산돌고딕 Neo 10pt 문단 끝 글자
  - `U3 top`: 10pt 글자 위 밑줄 + 30pt 표(마커도 글자 위 밑줄) + 10pt 문단 끝 글자
  - `유사가나다`: 20pt 밑줄 + 30pt 표 + 20pt 문단 끝 글자
  - `Z end`: 10pt 종결 문단
- 글자 모양 18개, 문단 모양 23개, 테두리/배경 3개, 1칸 표 6개(셀마다 10pt 빈 문단 하나),
  `HWPTAG_COMPATIBLE_DOCUMENT` 대상 프로그램 2
- PreviewText/PreviewImage stream, BinData storage 없음

## 한글.app 실측 (저장 줄 캐시·PDF 내보내기, pt)

`vertsize`(줄 상자)·`textheight`·`baseline`(상자 상단 → 베이스라인)·`spacing`(비율 여분)이고 PDF
베이스라인은 본문 상단 99.2 + `vertpos` + `baseline`과 0.1pt(한글 PDF의 0.12pt 장치 양자화) 안에서
같다. 한글은 끝 글자(문단 끝 글자·한 줄 끝 글자)의 글꼴 상자가 본문 상자보다 크면 **쌓는다** —
줄 상자 높이 = 끝 글자 상자 높이 + 본문 상자의 베이스라인 아래 몫, 베이스라인 = 둘 중 큰 값이다.
본문 상자는 글자 run 상자의 축별 합집합이다(Apple SD 산돌고딕 Neo·Menlo 10pt → 15.59 / 11.04,
아래 몫 4.55; Menlo만 → 15.15 / 11.04, 아래 몫 4.11). 본문 상자보다 큰 글자처럼 취급 개체도 개체
높이 + 본문 아래 몫이고, 본문 베이스라인과 본문 상자 높이 사이의 개체는 베이스라인만 옮긴다. 비율
줄 간격 여분의 기준은 개체가 아니라 max(본문 상자, 끝 글자 상자)다(`A1`·`O1` 0.6 × 24.24 ≈ 14.56,
`오삼가나` 0.6 × 31.19 ≈ 18.68, 표만 있는 문단 0.6 × 15.15 ≈ 9.08).

## 재생성 절차

1. `HwpxFixtures/compat-decorations/document.hwpx`(MS 워드 호환 문서 —
   `hh:compatibleDocument@targetProgram="MS_WORD"`)를 풀어 `header.xml`의 모든 언어 글꼴 목록에
   Helvetica·Times New Roman·Apple SD 산돌고딕 Neo를 덧붙이고(한글이 저장하며 한글 슬롯의 중복을
   접고 id를 다시 매긴다), `hh:charPr id="6"`을 복제해 위 조합의 글자 모양(밑줄은 빨강 `#FF0000`)을,
   `hh:paraPr id="0"`을 복제해 줄 간격 비율 160·100%·여백만 5pt·최소 26pt 문단 모양을 만든다.
   `section0.xml`은 첫 문단(`hp:secPr`)만 남기고 위 문단들로 갈아 끼운다 — 문단 끝 글자의 글자
   모양은 문단 마지막 빈 run(`<hp:run charPrIDRef="N"><hp:t/></hp:run>`), 한 줄 끝은 `<hp:t>` 안
   `<hp:lineBreak/>`, 표는 실선 테두리 1칸 글자처럼 취급 표(`treatAsChar="1"`, 여백 0)이고
   `hp:linesegarray`는 적지 않는다(한글이 새로 조판한다). 생성기는 `probes/223/gen223fx.py`(세션 밖
   스크래치 — `gen223.py`의 `Base`를 쓴다).
2. `/Applications/한컴오피스 한글.app`(bundle `com.hancom.office.hwp12.mac.general`,
   12.30.0 build 6446)에서 그 HWPX를 열어 `파일 > PDF로 저장하기...`로 실측 PDF를 내고,
   `파일 > 다른 이름으로 저장하기...` → **한글 문서 (*.hwp)**, 같은 세션에서 다시 → **한글
   표준 문서 (*.hwpx)**로 저장한다 (System Events 접근성 자동화).
3. `.hwp`를 이 디렉터리의 `document.hwp`로, `.hwpx`를 `HwpxFixtures/ms-word-paragraph-end-box/
   document.hwpx`로 복사하고 두 `manifest.json`의 기대값을 갱신한 뒤 `swift test --filter Fixture`를
   돌린다.
