# table-cell-spacing

`document.hwp`는 **한글 문서**(호환 문서 대상 프로그램 `HWP201X`)에 셀 간격(표 76 `cellSpacing`)이
있는 표와 없는 표의 원형 점선·긴 점선·실선 셀 테두리를 실은 HWPX를 한컴오피스 한글 12.30.0
(build 6446)에서 열어 2026-09-28에 `한글 문서 (*.hwp)`로 저장한 binary HWP fixture다. 한글이 셀
간격이 있는 표의 테두리를 **칸마다 네 변의 상자**로 그리는 규칙(#243)의 실물 근거다 — 원형 점선의
원은 단 구분선과 같은 점 무늬로 크고 성기고, 모서리는 만나는 두 변의 모양·굵기가 같으면 맞물리며
다르면 가로 변이 모서리를 덮고 세로 변이 물러난다. 같은 편집 세션에서 저장한 HWPX 쌍
(`HwpxFixtures/table-cell-spacing`)과 PDF 내보내기(1쪽)가 같은 문서다.

## 포함 기능

- 한 구역, 최상위 19문단(1쪽) — 첫 문단은 구역 정의를 품은 제목(`#243 table-cell-spacing`)이다.
  이어 표본마다 글자처럼 취급 표 하나 + 꼬리표(` #0`…` #8`, 7pt)를 실은 문단과 구분 문단(`-`)이
  번갈아 온다. 문단 모양은 왼쪽 정렬·줄 간격 비율 160%다.
- 표는 모두 표 테두리 없음, 셀 안 여백 0이고 셀마다 7pt 빈 문단 하나를 싣는다. 색은 초록
  `#00FF00` = 시험 변, 파랑 `#0000FF` = 굵은 실선 2.0mm 이웃 변, 빨강 `#FF0000` = 기준 실선 0.1mm다.
  한 행 표(`#0`~`#7`)는 끝에 테두리 없는 10pt 칸과 빨강 기준 칸(10pt)을 더해 한글 PDF에서 표 원점을
  정확히 잡게 했다.
  - `#0` 1×2 (칸 90×25pt) — 네 변 원형 점선(`CIRCLE`) 1.0mm, 셀 간격 283HWPUNIT(2.83pt)
  - `#1` 1×1 (90×25) — 네 변 원형 점선 0.4mm, 셀 간격 1HWPUNIT(0.01pt)
  - `#2` 1×1 (90×25) — 네 변 원형 점선 2.0mm, 셀 간격 850HWPUNIT(8.5pt)
  - `#3` 1×1 (90×25) — 네 변 원형 점선 1.0mm, 셀 간격 0 (대조군 — 격자 규칙)
  - `#4` 1×1 (90×25) — 위 변 원형 점선 1.0mm + 왼·오른 변 파랑 실선 2.0mm, 셀 간격 283
  - `#5` 1×1 (30×60) — 왼 변 원형 점선 1.0mm + 위·아래 변 파랑 실선 2.0mm, 셀 간격 283
  - `#6` 1×1 (90×60) — 네 변 긴 점선(`DOT`) 1.0mm, 셀 간격 283
  - `#7` 1×1 (30×60) — 왼 변 실선 1.0mm 초록 + 위·아래 변 파랑 실선 2.0mm, 셀 간격 283
  - `#8` 2×2 (칸 45×20) — 모든 칸 네 변 원형 점선 0.4mm, 셀 간격 283
- 표 9개(셀 수 4·3·3·3·3·3·3·3·4), `HWPTAG_COMPATIBLE_DOCUMENT` 대상 프로그램 0(`HWP201X`)
- PreviewText/PreviewImage stream, BinData storage 없음

## 재생성 절차

1. `HwpxFixtures/CharShape/document.hwpx`를 풀어 `header.xml`에 `hh:charPr id="0"`을 복제해 모든
   슬롯 함초롬바탕(글꼴 id 1) 7pt 글자 모양을, `hh:paraPr id="0"`을 복제해 왼쪽 정렬 줄 간격 비율
   160% 문단 모양을 만들고, 표본의 변 조합마다 `hh:borderFill`(`hh:leftBorder`·`hh:rightBorder`·
   `hh:topBorder`·`hh:bottomBorder`의 `type`·`width`·`color`)을 더한다. `section0.xml`은 제목 문단
   (`hp:secPr`)에 이어 위 표본을 `hp:linesegarray` **없이** 적는다 (한글이 새로 조판하게) — 표는
   `treatAsChar="1"`의 `hp:tbl`이고 `cellSpacing`·`hp:sz`(칸 합 + 셀 간격 × (칸 수 + 1))를 표본대로,
   칸마다 `hp:cellAddr`·`hp:cellSpan`·`hp:cellSz`와 여백 0의 `hp:cellMargin`, 표본별
   `borderFillIDRef`를 준다. 꼬리표는 표와 같은 run의 `<hp:t> #N</hp:t>`다. `mimetype`을
   `ZIP_STORED` 첫 항목으로 다시 압축한다.
2. 그 HWPX를 `open -b com.hancom.office.hwp12.mac.general`로 연다.
3. `파일 > PDF로 저장하기...`로 같은 세션의 PDF를 내보낸다 (1쪽, A4).
4. `파일 > 다른 이름으로 저장하기...` → 파일 형식 **한글 문서 (*.hwp)** → 파일명만 입력 →
   저장 (System Events: 저장 패널 `splitter group 1`의 `pop up button 2`·
   `text field "별도 저장:"`·`button "저장"`; 같은 이름이 있으면 시트의 `button "대치"`).
5. 같은 세션에서 다시 `다른 이름으로 저장하기...` → **한글 표준 문서 (*.hwpx)** → 저장해
   `HwpxFixtures/table-cell-spacing/document.hwpx`를 갱신한다.
6. 저장된 `.hwp`를 이 디렉터리의 `document.hwp`로 복사하고 `manifest.json`의 기대값을
   갱신한 뒤
   `swift test --filter "FixtureManifest|HwpxFixtureManifest|HwpxHwpEquivalence|FixtureRender|FixtureTableCellSpacing"`로
   검증한다.

생성 확인 환경:

- 앱: 한컴오피스 한글 (`com.hancom.office.hwp12.mac.general`)
- 버전: `12.30.0` build `6446`
- 생성일: 2026-09-28

## 한글.app 실측

같은 세션의 PDF 내보내기에서 표본마다 초록 요소(원·대시·실선)의 좌표를 빨강 기준 칸으로 잡은 칸
로컬 좌표(칸 왼 위 모서리 = 0, pt, 0.12pt 장치 격자)로 읽은 값이다.

- 셀 간격이 있으면 원형 점선의 원이 단 구분선과 같은 점 무늬다 — 간격·칠 지름(경로 + 윤곽 0.12)은
  0.4mm 4.20·1.80(`#1`, 셀 간격 1HWPUNIT), 1mm 10.56·4.44(`#0`), 2mm 20.76·8.52(`#2`). 셀 간격 0인
  `#3`은 격자라 1mm 5.76·3.00이다.
- 네 변이 같은 원형 점선이면 변마다 칸 모서리에서 시작한다 (`#0` 두 칸 모두 위 변 첫 원 0, 왼 변 원
  3개; `#8` 네 칸 모두 모서리에 원). 셀 간격 0인 `#3`은 가로 변이 세로 변 반폭 앞(−1.40)에서 시작한다.
- 이웃이 다르면 가로 변이 모서리를 덮고 세로 변이 물러난다 — `#4` 위 변 첫 원 −2.70(파랑 2mm 반폭),
  `#5` 왼 변 첫 원 +2.88, `#7` 실선 왼 변 y 2.88 ~ 57.36 (한글은 굵기를 장치 단위로 반올림해 위·아래
  물림이 24u·22u로 갈린다).
- 네 변이 같은 긴 점선이면 세로 변도 반폭 앞에서 시작한다 (`#6` 왼 변 첫 대시 −1.44 ~ 19.32, 둘째
  31.80; 위 변 −1.38 ~ 19.38, 둘째 31.86).
- 셀 간격은 칸끼리 떼어 놓을 뿐 무늬를 잇지 않는다 (`#8`의 네 칸이 같은 무늬).
- 세로 변을 먼저, 가로 변을 나중에 그린다 — `#4`는 파랑 세로 변 → 초록 위 변, `#5`는 초록 왼 변 →
  파랑 위·아래 변이라 `#5`의 물러난 첫 원(반지름 2.22)이 파랑 위 변 아래에 깔린다.
