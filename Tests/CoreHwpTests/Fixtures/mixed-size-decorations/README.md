# mixed-size-decorations

`document.hwp`는 **한글 문서**(호환 문서 대상 프로그램 `HWP201X`)의 한 줄에 크기가 다른
글자·문단 끝 글자·한 줄 끝·책갈피·글자처럼 취급 표를 섞어 글자 장식선을 실은 HWPX를
한컴오피스 한글 12.30.0 (build 6446)에서 열어 2026-09-25에 `한글 문서 (*.hwp)`로 저장한 binary
HWP fixture다. 한글이 **밑줄을 줄 단위로** 놓고(위 가장자리 = 줄 상자 바닥, 아래 가장자리 =
줄 상자 상단) 두께·선 모양 축척은 줄 **글자**의 기본 크기로 정하며, 장식선의 크기 기준이
슬롯 상대 크기 전 **글자 모양 기본 크기**라는 규칙(#226)의 실물 근거다. 같은 편집 세션에서
저장한 HWPX 쌍(`HwpxFixtures/mixed-size-decorations`)과 PDF 내보내기 좌표가 렌더 핀의
오라클이다.

글꼴은 한글 슬롯 **Apple SD 산돌고딕 Neo**, 라틴 슬롯 **Menlo**로 `hwp2007-decorations`와
같다 — 둘 다 macOS·iOS 기본 탑재이고 결정론 resolver(`HwpFontResolver.testDeterministic`)가
같은 글꼴을 고른다. 줄 배치 캐시를 한글이 적어 두었으므로 베이스라인이 한글과 같고, 밑줄
자리는 줄 상자 높이(글꼴과 무관)의 함수라 **쪽 좌표를 그대로 핀**할 수 있다.

## 포함 기능

- 한 구역, 13문단(2쪽) — 첫 문단은 구역 정의를 품은 제목(`크기가 섞인 줄의 장식선`, 10pt,
  장식 없음)이고, 나머지 12문단이 표본이다. 밑줄은 초록 `#00FF00`, 글자 위 밑줄은 파랑
  `#0000FF`, 취소선은 빨강 `#FF0000`이다.
  1. `M1 가나Ag` 10pt 밑줄 + ` 크게Ag` 40pt 무장식
  2. `M2 가나Ag` 10pt 글자 위 밑줄 + 40pt 문단 끝 글자
  3. `M3 가나 ` 10pt 밑줄 + 높이 40pt 글자처럼 취급 1칸 표(마커 10pt, 셀 `표`) + ` Ag` 10pt 밑줄
  4. `M4 가나 ` 10pt 밑줄 + 40pt 글자 모양 책갈피(`mark40`) + ` Ag` 10pt 밑줄
  5. `M5 ` 20pt 무장식 + `가나Ag` 10pt 밑줄 + 40pt 문단 끝 글자
  6. `M6 가나Ag` 10pt 밑줄 + 40pt 한 줄 끝(코드 10) + `다음 줄Ag` 10pt 밑줄 (두 줄)
  7. `M7 가나Ag` 기본 40pt·상대 크기 50% 밑줄
  8. `M8 가나Ag` 기본 40pt·상대 크기 50% 취소선
  9. `M9 가나Ag점선` 10pt 긴 점선 밑줄(`DOT`) + ` 크게` 40pt 무장식
  10. `M10 가나Ag00 …가나Ag11` 10pt 밑줄 + ` 끝` 40pt 무장식 (두 줄로 접힘)
  11. `M11 ` 10pt + `위첨자` 기본 20pt·상대 크기 50% 위 첨자 취소선 + ` 뒤` 10pt
  12. `M12 가나 ` 10pt 글자 위 밑줄 + 높이 40pt 글자처럼 취급 1칸 표 + ` Ag` 10pt 글자 위 밑줄
- 글자 모양 17개(한컴 기본 모양 7개 + `CharShape` 원본의 Apple SD 산돌고딕 Neo 10pt 1개 + 위
  표본의 장식 6종·무장식 10·20·40pt 3종), 글자처럼 취급 표 2개, 책갈피 1개,
  `HWPTAG_COMPATIBLE_DOCUMENT` 대상 프로그램 0(`HWP201X`)
- PreviewText/PreviewImage stream, BinData storage 없음

40pt 상자 줄은 6.00pt, 문단 끝 글자·한 줄 끝·책갈피·표가 상자를 키운 줄도 같다. 두께는 줄
**글자**의 가장 큰 기본 크기의 0.04배다: 40pt 무장식 글자가 있는 줄은 1.56pt, 문단 끝
글자·한 줄 끝·책갈피·표만 40pt인 줄은 10pt 몫 0.36pt, 20pt 무장식 글자 줄(M5)은 0.84pt. 한 줄
끝으로 나뉜 M6의 둘째 줄과 접힌 M10의 첫 줄은 10pt만 있어 −1.68pt다(줄마다 따로). 상대 크기
50%인 M7·M8은 20pt 글리프인데 선은 기본 40pt 자리·두께이고, M11의 위 첨자 취소선은 첨자로
옮겨진 베이스라인(8.88pt 위) 위 4.44pt = 0.35 × 12.8(= 20 × 0.64 — 상대 크기를 곱하지 않은
첨자 크기)에 20pt 두께다. M9의 점선 한 토막은 40pt 몫(5 × 0.057 × 40 = 11.40pt)이다.

## 재생성 절차

1. `HwpxFixtures/CharShape/document.hwpx`를 풀어 `header.xml`의 `hh:fontfaces` 각 언어에
   `Menlo`를 더하고, `hh:charPr id="0"`을 복제해 한글 슬롯 Apple SD 산돌고딕 Neo · 그 밖의
   슬롯 Menlo로 위 표본의 글자 모양(크기·`hh:underline`·`hh:strikeout`·`hh:relSz`·
   `hh:supscript`)을 만든다. `section0.xml`은 제목 문단(`hp:secPr`)에 이어 표본 12문단을
   `hp:linesegarray` **없이** 적는다 (한글이 새로 조판하게) — 문단 끝 글자의 글자 모양은
   마지막 빈 run(`<hp:run charPrIDRef="N"><hp:t/></hp:run>`), 한 줄 끝은
   `<hp:t><hp:lineBreak/></hp:t>`만 실은 run, 책갈피는 `<hp:ctrl><hp:bookmark/></hp:ctrl>`
   run으로 싣는다. `mimetype`을 `ZIP_STORED` 첫 항목으로 다시 압축한다.
2. 그 HWPX를 `open -b com.hancom.office.hwp12.mac.general`로 연다.
3. `파일 > PDF로 저장하기...`로 오라클 PDF를 내보내 벡터 좌표(PyMuPDF `rawdict`의 글자
   `origin`, `get_drawings()`의 색 선)를 읽는다.
4. `파일 > 다른 이름으로 저장하기...` → 파일 형식 **한글 문서 (*.hwp)** → 파일명만 입력 →
   저장 (System Events: 저장 패널 `splitter group 1`의 `pop up button 2`·
   `text field "별도 저장:"`·`button "저장"`; 같은 이름이 있으면 시트의 `button "대치"`).
5. 같은 세션에서 다시 `다른 이름으로 저장하기...` → **한글 표준 문서 (*.hwpx)** → 저장해
   `HwpxFixtures/mixed-size-decorations/document.hwpx`를 갱신한다.
6. 저장된 `.hwp`를 이 디렉터리의 `document.hwp`로 복사하고 `manifest.json`의 기대값을
   갱신한 뒤
   `swift test --filter "FixtureManifest|HwpxFixtureManifest|HwpxHwpEquivalence|FixtureDecorationLine"`로
   검증한다.

생성 확인 환경:

- 앱: 한컴오피스 한글 (`com.hancom.office.hwp12.mac.general`)
- 버전: `12.30.0` build `6446`
- 생성일: 2026-09-25
