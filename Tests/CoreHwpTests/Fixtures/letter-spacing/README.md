# letter-spacing

`document.hwp`는 **한글 문서**(호환 문서 대상 프로그램 0, `HWP201X`)에 글자 모양 자간(표 33) 표본 11문단을
실은 합성 HWPX를 한컴오피스 한글 12.30.0 (build 6523)에서 열어 2026-10-08에 `한글 문서 (*.hwp)`로 저장한
binary HWP fixture다. 한글이 자간을 **글자 크기가 아니라 그 글자의 전진량**(상대 크기·장평 적용 뒤)의 %로
더하고, 보통·고정폭 빈칸에는 라틴 항목 자간을 **빈칸 폭의 %**로 더하며 묶음 빈칸에는 더하지 않고, 줄의
**마지막 글자에는 자간을 주지 않고** 줄을 맞추는 규칙(#260)의 실물 근거다. 같은 편집 세션에서 저장한 HWPX
쌍(`HwpxFixtures/letter-spacing`)과 PDF 내보내기(1쪽)가 같은 문서이고, PDF의 글자 원점이 렌더 핀의 오라클이다
(`HwpKitTests/FixtureLetterSpacingTests.swift`).

글꼴은 `space-width`와 같이 한글 슬롯 **Apple SD 산돌고딕 Neo**, 라틴 슬롯 **Menlo**다 — 둘 다 macOS·iOS에
기본 탑재이고 결정론 resolver(`HwpFontResolver.testDeterministic`: Menlo + 한글 대체 Apple SD Gothic Neo)가
같은 글꼴을 고르므로 한글 PDF의 쪽 좌표를 어느 기기에서든 그대로 핀할 수 있다.

## 포함 기능

- 한 구역, 12문단(1쪽) — 첫 문단은 구역 정의와 제목 `#260 letter-spacing`(함초롬바탕 10pt)이고, 이어 11문단이
  표본마다 **표본 run** + 꼬리표(` #1`…` #11`, 함초롬바탕 5pt) + 문단 끝 글자(꼬리표 글자 모양)로 온다.
  오른쪽 정렬 두 문단(10·11)은 꼬리표를 **줄 앞**(`#10 `)에 둬 표본의 마지막 글자가 줄 끝이 되게 했다.
  표본은 기본 크기 20pt, 문단 모양은 줄 간격 비율 160%다. 아래 "한글 / 라틴"은 슬롯 자간·장평·상대 크기다.

  | 문단 | 텍스트 | 글자 모양 (한글 / 라틴) | 문단 모양 | 표본이 가르는 것 |
  |---|---|---|---|---|
  | 1 | `abcd 가나다라` | 자간 +20% / +20% | 왼쪽 | 글자 전진량 × 1.2, 빈칸 10pt × 1.2 |
  | 2 | `abcd 가나다라` | −20% / −20% | 왼쪽 | 글자 × 0.8, 빈칸 8pt |
  | 3 | `abcd ab` | 0 / 장평 50%·자간 +20% | 왼쪽 | 장평 적용 뒤 전진량 × 1.2, 빈칸은 장평과 무관한 12pt |
  | 4 | `abcd 가` | 0 / 상대 크기 50%·자간 −20% | 왼쪽 | 줄어든 전진량 × 0.8 |
  | 5 | `가나 다라 ab` | +20% / 0 | 왼쪽 | 한글 항목 자간은 빈칸에 닿지 않는다 |
  | 6 | `ab cd` | 0 / −10%, **글꼴에 어울리는 빈칸** | 왼쪽 | Menlo 빈칸 × 0.9 |
  | 7 | `ab`·`cd`·`ef` | 0 / +20% | 왼쪽 | **묶음 빈칸**(`hp:nbSpace`) 10pt(자간 없음)·**고정폭 빈칸**(`hp:fwSpace`) 6pt |
  | 8 | `aaaaa` × 10 | 0 / −20% | 왼쪽, 왼쪽 여백 37.70pt(줄 폭 387.5pt) | 첫 줄 6단어 |
  | 9 | `aaaaa` × 6 | 0 / +20% | 왼쪽, 왼쪽 여백 17.70pt(줄 폭 407.5pt) | 첫 줄 5단어 |
  | 10 | `abcd` | 0 / −20% | **오른쪽** | 마지막 `d`가 오른쪽 끝 − 12.04pt |
  | 11 | `abcd` | 0 / +20% | **오른쪽** | 같은 자리 |

- 표본은 모두 장식이 없고, 꼬리표·문단 끝 글자를 5pt로 두어 줄 상자에 끼어들지 않게 했다.
- 8번이 `aaaaa` × 10인 것은 문단 전체 폭(≈ 553pt)을 단 폭의 1.06배(450.7pt) 밖에 두려는 것이다 — 8단어(≈ 446pt)면
  조판의 '살짝 넘치는 한 줄' 허용(`HwpDrawnTextLayout.slightOverflowLineMetrics`)에 걸려 왼쪽 여백을 무시한 한
  줄로 그려진다(한글은 여백을 지킨 두 줄). 그 허용이 글자만 있는 줄을 가용 폭이 아니라 단 폭과 비교하는 것은 이
  픽스처의 축이 아닌 별개의 격차다.
- PreviewText/PreviewImage stream, BinData storage 없음

## 한글.app 실측 (같은 세션 PDF 내보내기, 쪽 왼쪽에서 pt)

Menlo 글자의 전진량은 0.6em(20pt 12.04pt), Apple SD 산돌고딕 Neo 한글 글자는 0.865em(17.3pt)이다. PDF 원점이
0.12pt 장치 단위로 양자화돼 ±0.06pt 흔들린다. 한글은 자간을 HWPUNIT(0.01pt) 단위로 0 쪽으로 버리는 것으로
보여(8번 문단 `a` 간격 9.6417pt = 12.04 − 2.40, 정확값 9.6328pt) 긴 줄에서는 글자당 0.01pt 미만씩 정확값 조판과
갈린다 — 렌더 핀의 허용 오차가 0.25pt + 글자당 0.01pt인 이유다.

## 재생성 절차

1. `HwpxFixtures/CharShape/document.hwpx`를 풀어 `header.xml`의 글꼴 목록에 Apple SD 산돌고딕 Neo·Menlo를
   더하고(모든 언어의 `fontCnt`를 함께 올린다), `hh:charPr id="0"`을 복제해 위 표본의 글자 모양을 만든다 —
   `height="2000"`, `hh:fontRef`(한글 슬롯 Apple SD 산돌고딕 Neo·라틴 슬롯 Menlo·나머지 함초롬바탕),
   `hh:spacing`(한글·라틴), `hh:ratio`(3번 라틴 50), `hh:relSz`(4번 라틴 50), `useFontSpace`(6번 `1`).
   꼬리표는 `height="500"`, 제목은 `height="1000"`의 함초롬바탕 글자 모양이다.
   `hh:compatibleDocument@targetProgram`은 `HWP201X` 그대로 둔다. `hh:paraPr id="0"`을 복제해 왼쪽·오른쪽
   정렬 줄 간격 비율 160% 문단 모양과, 8·9번의 왼쪽 여백(`hc:left` — `hp:case` 갈래는 HWPUNIT 값 3770·1770,
   `hp:default` 갈래는 그 두 배)을 준 문단 모양을 만든다. `section0.xml`은 첫 문단(`hp:secPr` + 제목)과 위
   순서의 11문단을 `hp:linesegarray` **없이** 적는다 (한글이 새로 조판하게). 7번은
   `ab<hp:nbSpace/>cd<hp:fwSpace/>ef`다. 생성기는 로컬 `probes/260/gen260fx.py`다. `mimetype`을
   `ZIP_STORED` 첫 항목으로 다시 압축한다.
2. 그 HWPX를 `open -b com.hancom.office.hwp12.mac.general`로 연다.
3. `파일 > PDF로 저장하기...`로 같은 세션의 PDF를 내보낸다 (1쪽, A4).
4. `파일 > 다른 이름으로 저장하기...` → 파일 형식 **한글 문서 (*.hwp)** → 파일명만 입력 → 저장
   (System Events: 저장 패널 `splitter group 1`의 `pop up button 2`·`text field "별도 저장:"`·
   `button "저장"`; 같은 이름이 있으면 시트의 `button "대치"`).
5. 같은 세션에서 다시 `다른 이름으로 저장하기...` → **한글 표준 문서 (*.hwpx)** → 저장해
   `HwpxFixtures/letter-spacing/document.hwpx`를 갱신한다.
6. 저장된 `.hwp`를 이 디렉터리의 `document.hwp`로 복사하고 `manifest.json`의 기대값을 갱신한 뒤
   `swift test --filter "FixtureManifest|HwpxFixtureManifest|HwpxHwpEquivalence|FixtureRender|FixtureLetterSpacing"`로
   검증한다.

생성 확인 환경:

- 앱: 한컴오피스 한글 (`com.hancom.office.hwp12.mac.general`)
- 버전: `12.30.0` build `6523`
- 생성일: 2026-10-08
