# dash-patterns

`document.hwp`는 **한글 문서**(호환 문서 대상 프로그램 `HWP201X`)에 대시 무늬(긴 점선·점선·일점쇄선·
이점쇄선·긴 파선)를 표 셀 테두리·취소선·단 구분선 세 자리에 실은 합성 HWPX를 한컴오피스 한글 12.30.0
(build 6446)에서 열어 2026-10-01에 `한글 문서 (*.hwp)`로 저장한 binary HWP fixture다. 한글이 대시
무늬의 **선·공백 길이**와 표 셀 테두리·단 구분선의 **획 두께**를 600dpi 장치 단위(u = 0.12pt)
정수로 그린다는 규칙(#245)의 실물 근거다 — 셀 테두리는 셀 간격이 없으면 격자 식, 있으면 단 구분선과
같은 점 무늬 식으로 재고(1mm 점선 35·52u vs 35·53u), 글자선은 무늬 두께 round(글자 크기 × 0.039)의
식으로 잰다. 같은 편집 세션에서 저장한 HWPX 쌍(`HwpxFixtures/dash-patterns`)과 PDF 내보내기(2쪽)가
같은 문서이고, PDF 벡터 좌표가 렌더 핀의 오라클이다 (`HwpKitTests/FixtureDashPatternTests.swift`).

## 포함 기능

- 한 구역, 최상위 31문단(2쪽) — 첫 문단은 구역 정의를 품은 제목(`#245 dash-patterns`)이다. 이어
  표본마다 표본 문단과 구분 문단(`-`)이 번갈아 온다. 문단 모양은 왼쪽 정렬·줄 간격 비율 160%,
  글자 모양은 모든 슬롯 함초롬바탕(글꼴 id 1)이고 꼬리표(` #0`…` #13`)는 7pt다. 선 색은 초록
  `#00FF00` = 시험 선, 파랑 `#0000FF` = 굵은 실선 2.0mm 이웃 변, 빨강 `#FF0000` = 기준 실선 0.1mm다.
- 1쪽 표본 `#0`~`#8`은 글자처럼 취급 표 + 꼬리표다. 표는 모두 표 테두리 없음, 셀 안 여백 0이고 셀마다
  7pt 빈 문단 하나를 싣는다. 한 행 표(`#0`~`#7`)는 위 변만 초록인 시험 칸(330×20pt) 뒤에 테두리 없는
  10pt 칸과 빨강 기준 칸(10pt)을 더해 한글 PDF에서 시험 칸 원점을 정확히 잡게 했다.
  - `#0` 긴 점선(`DOT`) 0.12mm, 셀 간격 0 / `#1` 같은 변, 셀 간격 283HWPUNIT(2.83pt)
  - `#2` 점선(`DASH`) 1.0mm, 셀 간격 0 / `#3` 같은 변, 셀 간격 283
  - `#4` 긴 파선(`LONG_DASH`) 2.0mm, 셀 간격 0 / `#5` 같은 변, 셀 간격 283
  - `#6` 일점쇄선(`DASH_DOT`) 0.5mm, 셀 간격 0
  - `#7` 이점쇄선(`DASH_DOT_DOT`) 1.5mm, 셀 간격 283
  - `#8` 1×2 (칸 165×20pt 둘) — 두 칸 모두 위 변 긴 점선 0.4mm + 왼·오른 변 파랑 실선 2.0mm, 셀 간격 0
    (두 칸 위 변의 사슬 #238과 굵은 세로 변 옆 연장), 끝에 빈 칸·빨강 기준 칸
- 1쪽 표본 `#9`~`#13`은 초록 취소선을 단 `가` run(약 300pt) + 꼬리표다 — `#9` 긴 점선 20pt(15자),
  `#10` 점선 11.54pt(1154HWPUNIT, 26자 — 무늬 두께 45HWPUNIT로 점 단위 반올림이 0.5u 동점에 걸린다),
  `#11` 긴 파선 10pt(30자), `#12` 일점쇄선 40pt(8자), `#13` 긴 점선 7pt(43자).
- 2쪽(쪽 나누기)은 2단 밴드(`NEWSPAPER`, 단 2개, 같은 너비, 간격 2268HWPUNIT)다 — 단 구분선
  일점쇄선 0.4mm 초록, 20pt `#14` + 한 줄 끝(코드 10)으로 나눈 `가` 13줄. 이어 1단으로 돌아온 `-` 문단.
- 표 9개(셀 수 3·3·3·3·3·3·3·3·4), 단 정의 3개(1단·2단·1단), 취소선 글자 모양 5개,
  `HWPTAG_COMPATIBLE_DOCUMENT` 대상 프로그램 0(`HWP201X`)
- PreviewText/PreviewImage stream, BinData storage 없음

## 한글.app 실측

같은 세션의 PDF 내보내기에서 초록 조각을 표본마다 읽은 값이다 (u = 0.12pt). 표는 빨강 기준 칸으로 잡은
칸 로컬 좌표(칸 왼 위 모서리 = 0, pt)이고, 글자선·단 구분선은 첫 조각 시작 = 0이다.

| 표본 | 무늬 (선·공백, u) | 획 두께 (u) | 조각 수 | 첫 조각 · 마지막 조각 |
|---|---|---:|---:|---|
| `#0` 긴 점선 0.12mm, 셀 간격 0 | 20·12 | 3 | 86 | −0.08 ~ 2.32 · 326.32 ~ 328.72 |
| `#1` 긴 점선 0.12mm, 셀 간격 283 | 20·12 | 3 | 86 | −0.06 ~ 2.34 · 326.34 ~ 328.74 |
| `#2` 점선 1mm, 셀 간격 0 | 35·52 | 24 | 32 | −0.08 ~ 4.12 · 323.56 ~ 327.76 |
| `#3` 점선 1mm, 셀 간격 283 | 35·53 | 24 | 32 | −0.06 ~ 4.14 · 327.30 ~ 330.18 |
| `#4` 긴 파선 2mm, 셀 간격 0 | 693·207 | 47 | 4 | −0.08 ~ 83.08 · 323.92 ~ 330.16 |
| `#5` 긴 파선 2mm, 셀 간격 283 | 693·208 | 47 | 4 | −0.06 ~ 83.10 · 324.30 ~ 330.18 |
| `#6` 일점쇄선 0.5mm, 셀 간격 0 | 172·51·17·51 | 12 | 19 | −0.08 ~ 20.56 · 314.20 ~ 330.16 |

- 선·공백과 획 두께가 모두 장치 단위 정수다 — 굵기 0.12mm·1mm·2mm의 획이 3u·24u·47u(0.36·2.88·
  5.64pt)로 그려진다.
- 셀 간격이 있으면 같은 점선·긴 파선의 공백이 1u 길다(`#2`/`#3` 52/53u, `#4`/`#5` 207/208u) — 셀 간격이
  없는 표는 격자 식, 있는 표는 단 구분선과 같은 점 무늬 식으로 잰다.
- 표 원점이 장치 격자에 맞춰져 첫 조각이 −0.06~−0.08pt에서 시작하고, 끝까지 그리는 무늬는 선 끝에서
  장치 한 칸을 더 그린다(330.16~330.18). `#8`은 두 칸 위 변이 한 사슬이고 양 끝이 파랑 2mm 세로 변
  획(47u)의 절반만큼 나간다 (한글은 23u·24u로 격자에 맞춘다).

## 재생성 절차

1. `HwpxFixtures/CharShape/document.hwpx`를 풀어 `header.xml`에 `hh:charPr id="0"`을 복제해 모든
   슬롯 함초롬바탕(글꼴 id 1)의 7pt 꼬리표 글자 모양과 `#9`~`#13`의 취소선 글자 모양(`height`,
   `hh:strikeout@shape`·`@color`)을, `hh:paraPr id="0"`을 복제해 왼쪽 정렬 줄 간격 비율 160% 문단
   모양을 만들고, 표본의 변 조합마다 `hh:borderFill`(`hh:leftBorder`·`hh:rightBorder`·`hh:topBorder`·
   `hh:bottomBorder`의 `type`·`width`·`color`)을 더한다. `section0.xml`은 제목 문단(`hp:secPr`)에 이어
   위 표본을 `hp:linesegarray` **없이** 적는다 (한글이 새로 조판하게) — 표는 `treatAsChar="1"`의
   `hp:tbl`이고 `cellSpacing`·`hp:sz`(칸 합 + 셀 간격 × (칸 수 + 1))를 표본대로, 칸마다
   `hp:cellAddr`·`hp:cellSpan`·`hp:cellSz`와 여백 0의 `hp:cellMargin`, 표본별 `borderFillIDRef`를 준다.
   2쪽은 `pageBreak="1"` 문단의 첫 run에 `hp:colPr`(`type="NEWSPAPER"`·`colCount="2"`·
   `sameGap="2268"`, `hp:colLine type="DASH_DOT" width="0.4 mm"`)을, 마지막 `-` 문단에 `colCount="1"`의
   `hp:colPr`을 둔다. 생성기는 로컬 `probes/245/gen245fx.py`다. `mimetype`을 `ZIP_STORED` 첫 항목으로
   다시 압축한다.
2. 그 HWPX를 `open -b com.hancom.office.hwp12.mac.general`로 연다.
3. `파일 > PDF로 저장하기...`로 같은 세션의 PDF를 내보낸다 (2쪽, A4).
4. `파일 > 다른 이름으로 저장하기...` → 파일 형식 **한글 문서 (*.hwp)** → 파일명만 입력 →
   저장 (System Events: 저장 패널 `splitter group 1`의 `pop up button 2`·
   `text field "별도 저장:"`·`button "저장"`; 같은 이름이 있으면 시트의 `button "대치"`).
5. 같은 세션에서 다시 `다른 이름으로 저장하기...` → **한글 표준 문서 (*.hwpx)** → 저장해
   `HwpxFixtures/dash-patterns/document.hwpx`를 갱신한다.
6. 저장된 `.hwp`를 이 디렉터리의 `document.hwp`로 복사하고 `manifest.json`의 기대값을
   갱신한 뒤
   `swift test --filter "FixtureManifest|HwpxFixtureManifest|HwpxHwpEquivalence|FixtureRender|FixtureDashPattern"`로
   검증한다.

생성 확인 환경:

- 앱: 한컴오피스 한글 (`com.hancom.office.hwp12.mac.general`)
- 버전: `12.30.0` build `6446`
- 생성일: 2026-10-01
