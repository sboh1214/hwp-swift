# section-page-starts-on

`document.hwp`는 한컴오피스 한글 12.30.0 (build 6446)에서 빈 문서로 시작해 구역 4개를
만들고 `쪽 > 구역 설정... > 종류`를 구역마다 다르게 설정해 2026-09-11에 저장한 binary
HWP fixture다. 같은 편집 세션에서 `한글 표준 문서 (*.hwpx)`로도 저장해
`HwpxFixtures/section-page-starts-on/document.hwpx` 쌍을 만들었다 — HWPX
`hp:startNum@pageStartsOn`의 홀수·짝수 값이 뒤바뀌어 있던 매핑(#173)의 실측 오라클이다.

## 포함 기능

4쪽, 구역 4개, 문단 5개(첫 구역만 2문단). 컨트롤 8개(구역·단 각 4). 표·그림·주석·쪽
번호 매기기는 없다.

| 구역 | 본문 | 구역 설정 > 종류 | 구역 정의 `property` | bits 20-21 | `pageStartNumber` | 한글 쪽 번호 |
|---|---|---|---|---:|---:|---:|
| 1 | `구역 시작 종류 견본` / `첫째 구역 이어서` | 이어서 | `0x00000000` | 0 | 0 | 1 |
| 2 | `둘째 구역 홀수` | 홀수 | `0x00200000` | 2 | 0 | 3 |
| 3 | `셋째 구역 짝수` | 짝수 | `0x00100000` | 1 | 0 | 4 |
| 4 | `넷째 구역 사용자` | 사용자, 시작 번호 5 | `0x00000000` | 0 | 5 | 5 |

구역 정의 컨트롤 payload의 앞 8바이트는 순서대로 `64 63 65 73 00 00 00 00`,
`64 63 65 73 00 00 20 00`, `64 63 65 73 00 00 10 00`, `64 63 65 73 00 00 00 00`이고
넷째 구역의 쪽 번호 필드(오프셋 20)는 `05 00`이다. 즉 한글은 **홀수를 2, 짝수를 1**로
저장한다 — 한컴 공개 OWPML 모델 `enumdef.h`의 `STARTNUMSTARTONTYPE`(BOTH 0 · EVEN 1 ·
ODD 2)과 같다. 스펙 표 130은 이 비트의 값을 적지 않아 종전 HWPX 매핑이 `ODD → 1`을
가정했었다. 사용자 지정 시작 번호는 종류 비트 0에 `pageStartNumber`로 따로 실린다.

**한글 12.30.0 macOS는 홀수·짝수 시작 때문에 빈 쪽을 끼우지 않는다** — 상태 표시줄이
둘째 쪽에서 `3/4쪽`, 셋째 쪽에서 `4/4쪽`, 넷째 쪽에서 `5/4쪽`을 보이고(물리 4쪽에 쪽
번호 1·3·4·5), `파일 > PDF로 저장하기`도 4쪽을 낸다. 렌더 쪽수 핀(`pageCount` 4)의 근거다.
저장한 `.hwp`와 `.hwpx`의 사본을 각각 다시 열어 구역마다 `쪽 > 구역 설정...`을 확인했다 —
두 저장본 모두 종류가 이어서·홀수·짝수·사용자(시작 5)로 읽히고 쪽 번호도 같다.

## 재생성 절차

1. 한컴오피스 한글에서 새 빈 문서를 만들고 `구역 시작 종류 견본` Return `첫째 구역 이어서`
   입력.
2. `쪽 > 구역 나누기`, `둘째 구역 홀수` 입력, `쪽 > 구역 설정...` → 종류 **홀수** → 설정.
3. `쪽 > 구역 나누기`, `셋째 구역 짝수` 입력, `쪽 > 구역 설정...` → 종류 **짝수** → 설정
   (새 구역은 앞 구역의 종류를 물려받아 대화상자가 홀수로 열린다).
4. `쪽 > 구역 나누기`, `넷째 구역 사용자` 입력, `쪽 > 구역 설정...` → 종류 **사용자**,
   시작 번호 **5** → 설정.
5. `파일 > 다른 이름으로 저장하기...`로 `한글 문서 (*.hwp)` 저장, **같은 세션에서** 다시
   `한글 표준 문서 (*.hwpx)`로도 저장해 `HwpxFixtures/section-page-starts-on/document.hwpx`를
   만든다.
6. 저장본을 이 디렉터리의 `document.hwp`로 복사하고 `manifest.json`을 갱신한 뒤
   `swift test --filter "FixtureManifestTests|HwpxHwpEquivalenceTests|HwpxSectionInvariant"`를
   실행한다.

생성 확인 환경:

- 앱: 한컴오피스 한글 (`com.hancom.office.hwp12.mac.general`)
- 버전: `12.30.0` build `6446`
- 생성일: 2026-09-11 (Claude Computer Use GUI 자동화 — 한국어 본문은 클립보드 붙이기,
  대화상자는 접근성 API로 조작)
